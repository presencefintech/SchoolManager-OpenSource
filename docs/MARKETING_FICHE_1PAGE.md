## Presence en 30 secondes

**Presence** connecte votre école, vos parents et votre trésorerie sur une seule plateforme : présence biométrique ou QR, paiement Mobile Money depuis le téléphone, notifications instantanées. Conçu pour la RDC et l’Afrique centrale.

## 6 problèmes résolus

| Aujourd’hui | Avec Presence |
|-------------|---------------|
| Cahiers papier, erreurs | Scan biométrique / QR + cahier numérique |
| Files au guichet | Paiement 24h/24 depuis le téléphone |
| Impayés mal suivis | Dashboard live + relances automatiques |
| Parents informés en retard | Push dès l’entrée ou l’absence de l’enfant |
| Reçus contestés | PDF + QR vérifiable publiquement |
| Inscription chaotique | Pipeline numérique + pré-inscription |

---

## Comment démarrer (5 étapes)

1. **Création de l’école** sur la plateforme (espace isolé, sécurisé).
2. **Configuration** : classes, frais, personnel.
3. **Inscription élèves** → code d’activation remis à chaque parent.
4. **Parent active l’app** avec téléphone + code + mot de passe.
5. **Vie quotidienne** : scan présence → notification · paiement → reçu · direction suit tout en direct.

> **1 code = 1 élève.** Pour un 2ᵉ enfant, nouveau code — même compte parent.

## Sécurité & confiance

- Données **isolées par école** (multi-tenant)
- Biométrie avec **détection de vivacité** (anti-photo)
- **KYC bancaire** avant paiements en ligne
- Versement sur **le compte de l’école** — RIB jamais exposé aux parents
- Journal d’audit · MFA personnel · Verrouillage après échecs de connexion
